# TornadoSafe – Web GIS Application

TornadoSafe is an interactive Web GIS application developed for **tornado shelter accessibility and preparedness planning in Calhoun County, Alabama**.

### Features
- Interactive map displaying 22 tornado shelters.
- Find the five nearest shelters based on driving time.
- View estimated driving distances and travel times.
- Display driving routes to selected shelters.
- View active severe weather alerts from the National Weather Service.

### Technologies Used
HTML, CSS, JavaScript, Leaflet, OpenStreetMap, GeoJSON, openrouteservice API, and National Weather Service API.

### Live Application
https://monika1269.github.io/TornadoSafe/

### Data Sources
- Calhoun County Emergency Management Agency (EMA)
- OpenStreetMap
- openrouteservice
- National Weather Service (NWS)

### Note
This application is intended for advance preparedness planning. Driving times are estimates, and shelter availability is not guaranteed.
